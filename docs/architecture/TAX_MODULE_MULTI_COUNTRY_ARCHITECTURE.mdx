## Overview

This document outlines the architecture for building a globally extensible, multi-country tax calculation system from the ground up for the Ampairs platform, with offline-first capabilities and support for diverse tax regimes worldwide.

**Note:** This is a **greenfield implementation** for a fresh system. No legacy data migration is required.

### Goals

- ✅ Support tax systems from multiple countries (India, USA, UK, EU, Canada, Australia, etc.)
- ✅ Maintain offline-first architecture for seamless operation
- ✅ Provide flexible tax component identification (CGST/SGST, VAT, Sales Tax, etc.)
- ✅ Enable -level country configuration
- ✅ Support complex tax scenarios (compound taxes, tiered rates, jurisdiction-based)
- ✅ Ensure compliance with country-specific tax regulations

### Non-Goals

- ❌ Real-time tax rate updates from government APIs
- ❌ Automatic tax filing/reporting (future consideration)
- ❌ Multi-currency tax calculation (handled separately)

## Design Principles

### 1. **Offline-First Architecture**

All tax calculations must work completely offline:
- Tax component definitions cached in Room database
- Tax rules stored locally with sync status
- Calculation engine uses only local data
- Background sync when online

### 2. **Component-Based Flexibility**

Tax systems decomposed into reusable components:
- Each country defines its tax components (CGST, VAT, Sales Tax, etc.)
- Components have configurable rates, calculation methods, and rules
- Rules compose multiple components for complete tax calculation

### 3. **-Scoped Configuration**

Each  can have different tax settings:
- Country selection determines tax strategy
- Tax rules specific to  + country
- Proper isolation using  context

### 4. **Strategy Pattern for Countries**

Pluggable strategies for different tax systems:
- `ITaxCalculationStrategy` interface
- Country-specific implementations (IndiaGSTStrategy, USASalesTaxStrategy, etc.)
- Runtime strategy selection based on  country

### 5. **Scalability & Extensibility**

Built for growth and adaptation:
- Easy addition of new countries without code changes
- Template-based tax rule creation
- Admin UI for tax configuration management
- Support for future tax law changes

## Tax Component System

### Component Categories

Tax components are classified into hierarchical categories:

| Category | Description | Examples |
|----------|-------------|----------|
| **FEDERAL** | National-level taxes | IN: CGST, IGST; CA: GST; UK: VAT |
| **STATE** | State/Province level | IN: SGST; US: State Tax; CA: PST |
| **COUNTY** | County/District level | US: County Tax |
| **CITY** | City/Municipal level | US: City Tax |
| **SURCHARGE** | Additional charges | IN: CESS, Additional Cess |
| **SPECIAL** | Special district taxes | US: Special District Tax |
| **COMBINED** | Harmonized taxes | CA: HST (combines GST+PST) |

### Calculation Methods

| Method | Description | Use Case |
|--------|-------------|----------|
| **PERCENTAGE** | Tax as % of base | Most common (CGST, VAT, Sales Tax) |
| **FIXED** | Fixed amount per unit | Excise duties, specific taxes |
| **TIERED** | Different rates for different slabs | Progressive tax systems |
| **COMPOUND** | Tax calculated on base + previous taxes | Quebec QST on GST+base |

### Component Relationships

**Pairing Rules:**
- India: CGST always pairs with SGST for intra-state
- Canada Quebec: QST compounds on GST
- USA: State + County + City are additive

**Mutual Exclusivity:**
- India: CGST+SGST OR IGST (not both)
- Canada: GST+PST OR HST (not both)

## Calculation Engine

### Strategy Interface

```kotlin
interface ITaxCalculationStrategy {
    val countryCode: String
    val strategyName: String

    /**
     * Calculate tax using local rules from Room database
     * Must work completely offline
     */
    suspend fun calculateTax(
        taxCode: String,
        baseAmount: Double,
        quantity: Int,
        sourceLocation: TaxJurisdiction,
        destinationLocation: TaxJurisdiction,
        transactionContext: TransactionContext
    ): Result<TaxCalculationResult>

    /**
     * Validate tax code format (offline validation)
     */
    fun validateTaxCode(code: String, codeType: TaxCodeType): Boolean

    /**
```

```kotlin
class TaxCalculationEngine(
    private val taxRuleDao: TaxRuleDao,
    private val taxComponentDao: TaxComponentDao,
    private val componentTypeDao: TaxComponentTypeDao,
    private val ConfigDao: TaxConfigDao,

    suspend fun calculateTax(request: TaxCalculationRequest): Result<TaxCalculationResult> {
        // 1. Get  configuration
        val Id = Context.getCurrentId()

        val config = ConfigDao.getById(Id)
            ?: getDefaultConfig(Id)

        // 2. Get strategy for country

            baseAmount = request.baseAmount,
            quantity = request.quantity,
            sourceLocation = request.sourceLocation,
            destinationLocation = request.destinationLocation,
            transactionContext = request.transactionContext
        )
    }

        return strategyCache.getOrPut(config.taxStrategy) {
            when (config.taxStrategy) {
                "INDIA_GST" -> IndiaGSTStrategy(taxRuleDao, taxComponentDao, componentTypeDao, Context)
                "USA_SALES_TAX" -> USASalesTaxStrategy(...)
                "EU_VAT" -> EUVATStrategy(...)
                "CANADA_GST_HST" -> CanadaGSTHSTStrategy(...)
                else -> DefaultTaxStrategy(...)
            }
        }
    }
```

## Offline-First Strategy

### Data Synchronization

**Initial Setup:**
```
Admin selects country → Backend provides templates → Mobile downloads → Room DB cached
```

**Periodic Sync:**
```
Every 24h or on-demand:
Mobile → GET /api/v1/s/{id}/tax/rules?modifiedAfter=timestamp
Backend → Returns changed rules only (incremental)
Mobile → Upserts to Room DB
```

**Conflict Resolution:**
```
Local rule modified + Backend rule changed:
→ Mark as CONFLICT in sync_status
→ Admin reviews in UI
→ Resolution pushed to backend
```

### Offline Capabilities

✅ **Full Tax Calculation**: All calculations work without network
✅ **Component Lookup**: Component types cached locally
✅ **Rule Application**: Rules stored in Room database
✅ **Validation**: Tax code format validation offline
✅ **History**: Complete calculation history available

```kotlin
class TaxConfigurationSyncService(
    private val taxConfigApi: TaxConfigurationApi,
    private val taxRuleDao: TaxRuleDao,
    private val ConfigDao: TaxConfigDao,
    private val Context: ContextManager
) {
    suspend fun syncTaxConfiguration(): Result<Int> {
        val Id = Context.getCurrentId() ?: return Result.failure(...)

        // 1. Get  config
        val configResult = taxConfigApi.getTaxConfiguration(Id)
        if (configResult.isSuccess) {
            ConfigDao.upsert(configResult.getOrThrow().toEntity())
        }

        // 2. Get last sync timestamp
        val lastSync = ConfigDao.getById(Id)?.syncedAt ?: 0L

        // 3. Fetch updated rules (incremental)
        val rulesResult = taxConfigApi.getTaxRules(
            Id = Id,
            modifiedAfter = lastSync
        )

        // 4. Upsert to Room DB
        if (rulesResult.isSuccess) {
            val rules = rulesResult.getOrThrow()
            rules.forEach { rule ->
                taxRuleDao.upsert(rule.toEntity().copy(
                    syncStatus = "SYNCED",
                    lastSyncedAt = Clock.System.now().toEpochMilliseconds()
                ))
            }

            ConfigDao.updateSyncTime(Id, Clock.System.now().toEpochMilliseconds())
            return Result.success(rules.size)
        }

        return Result.failure(...)
    }
}
```

```kotlin
class TaxCodeRepository(
    private val taxCodeApi: TaxCodeApi,
    private val TaxCodeDao: TaxCodeDao,
    private val Context: ContextManager
) {

    /**
     * Search master tax codes (server-side only, requires network)
     */
    suspend fun searchMasterCodes(
        query: String,
        countryCode: String
    ): Result<List<MasterTaxCode>> {
        return try {
            val response = taxCodeApi.searchMasterTaxCodes(
                query = query,
                countryCode = countryCode,
                page = 0,
                size = 50
            )
            Result.success(response.content)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }

    /**
     * Subscribe  to tax code (creates  tax code)
     */
    suspend fun subscribeToTaxCode(masterTaxCodeId: String): Result<TaxCode> {
        val Id = Context.getCurrentId()
            ?: return Result.failure(Exception("No  selected"))

        return try {
            // Call server to subscribe
            val request = SubscribeTaxCodeRequest(masterTaxCodeId)
            val TaxCode = taxCodeApi.subscribeToTaxCode(Id, request)

            // Save to local database
            TaxCodeDao.insert(TaxCode.toEntity())

            Result.success(TaxCode)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }

    /**
     * Get  subscribed codes (offline available)
     */
    fun observeTaxCodes(): Flow<List<TaxCode>> {
        val Id = Context.getCurrentId()
            ?: return flowOf(emptyList())

        return TaxCodeDao.observeTaxCodes(Id)
            .map { entities -> entities.map { it.toDomain() } }
    }

    /**
     * Sync  tax codes (background sync)
     */
    suspend fun syncTaxCodes(): Result<Int> {
        val Id = Context.getCurrentId()
            ?: return Result.failure(Exception("No  selected"))

        return try {
            val lastSync = TaxCodeDao.getLastSyncTime(Id) ?: 0L

            val result = taxCodeApi.getTaxCodes(
                Id = Id,
                modifiedAfter = lastSync
            )

            val codes = result.content
            codes.forEach { code ->
                TaxCodeDao.upsert(code.toEntity())
            }

            Result.success(codes.size)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }
}
```

### 2. USA Sales Tax Strategy

**Tax Components:**
- State Sales Tax
- County Tax
- City Tax
- Special District Tax

**Logic:**
```
Determine nexus (physical presence)
If has nexus in destination state:
    Apply State Tax
    Apply County Tax (if applicable)
    Apply City Tax (if applicable)
    Apply Special District Tax (if applicable)
```

### 3. EU VAT Strategy

**Tax Components:**
- Standard VAT (varies by country: 19-27%)
- Reduced VAT (5-15%)
- Super-reduced VAT (0-10%)

**Logic:**
```
If intra-EU B2B transaction:
    Apply Reverse Charge (0% VAT)
Else if intra-EU B2C:
    Apply destination country VAT
Else:
    Apply origin country VAT
```

**Example Configuration (Germany):**
```json
{
  "b2c": {
    "components": [
      { "id": "VAT_STANDARD", "rate": 19.0, "order": 1 }
    ]
  },
  "b2b": {
    "components": [
      { "id": "VAT_REVERSE_CHARGE", "rate": 0.0, "order": 1 }
    ]
  }
}
```

### 4. Canada GST/HST Strategy

**Tax Components:**
- GST (Goods and Services Tax) - Federal 5%
- PST (Provincial Sales Tax) - Provincial
- HST (Harmonized Sales Tax) - Combined
- QST (Quebec Sales Tax) - Compound on GST

**Logic:**
```
If province uses HST:
    Apply HST only
Else if province is Quebec:
    Apply GST
    Apply QST (compound on GST + base)
Else:
    Apply GST
    Apply PST (if province has PST)
```

**Example Configuration (Quebec):**
```json
{
  "standard": {
    "components": [
      { "id": "GST", "rate": 5.0, "order": 1, "compound": false },
      { "id": "QST", "rate": 9.975, "order": 2, "compound": true }
    ]
  }
}
```

### 5. Australia GST Strategy

**Tax Components:**
- GST (10%)
- GST-free (0%)
- Input-taxed (exempt)

**Logic:**
```
If item is GST-free:
    Apply 0% GST
Else if item is input-taxed:
    No GST
Else:
    Apply 10% GST
```

**Example Configuration:**
```json
{
  "standard": {
    "components": [
      { "id": "GST", "rate": 10.0, "order": 1 }
    ]
  }
}
```

###  Initialization

When a new  is created, automatically configure tax settings based on selected country:

```kotlin
@Service
class InitializationService {

    suspend fun initializeTaxConfiguration(
        Id: String,
        countryCode: String
    ) {
        // 1. Create  tax configuration
        val config = TaxConfiguration(
            id = UUID.randomUUID(),
            Id = Id,
            countryCode = countryCode,
            taxStrategy = getTaxStrategyForCountry(countryCode),
            defaultTaxCodeSystem = getTaxCodeSystemForCountry(countryCode),
            taxJurisdictions = getDefaultJurisdictionsForCountry(countryCode)
        )
        configRepository.save(config)

        // 2. Load default templates for the country
        val templates = templateRepository.findByCountryCode(countryCode)

        // 3. Create default tax rules from templates
        templates.forEach { template ->
            createTaxRulesFromTemplate(Id, template)
        }
    }

    private fun getTaxStrategyForCountry(countryCode: String): String {
        return when (countryCode) {
            "IN" -> "INDIA_GST"
            "US" -> "USA_SALES_TAX"
            "GB" -> "UK_VAT"
            "CA" -> "CANADA_GST_HST"
            "AU" -> "AUSTRALIA_GST"
            else -> "DEFAULT_TAX"
        }
    }
}
```
